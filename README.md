## About

My day job is reconciliation: matching invoices to payments across 20+ retail and
marketplace accounts, finding short payments, duplicates and unapplied credits, and
helping automate that work with Python, SQL and Excel.

The projects below are built around the same problems. Where it applies, they validate
their input, reject bad rows with a reason, handle money in exact decimals and come
with tests. They use generated or public sample data, never data from a client or
employer. Where a first version of mine had a bug, the README says what it was.
